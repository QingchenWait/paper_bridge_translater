# 纸间 · Paper Bridge

一个无需后端、可静态部署的 PDF 阅读与 AI 翻译应用。版本 **0.4.0**。浏览器标签标题为“纸间 · 文献翻译”。新增本地离线机器翻译，翻译文本无需发送到服务器。

## 开始使用

需要 Node.js 22.13+（建议 24 LTS）。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173`。启动引导中可以配置 AI 服务，也可以选择“直接进入 APP”，直接使用词典和句子翻译。“不再显示”自绘开关默认关闭；只有手动打开它，之后进入软件才跳过引导，否则每次进入都会显示。旧版完成引导不会自动开启此开关，已有 API 配置继续保留。

启动窗口标题为“纸间 · 文献翻译 & AI 分析”，两个进入按钮居中，“不再显示”文字与开关位于右下角；右上角可关闭窗口。作者名 [@CyanDust_青尘](https://space.bilibili.com/385556208) 在新标签页打开工作室主页。仅关闭窗口不会开启“不再显示”。

启动配置页的 API Key 右侧提供“获取”，根据当前 Base URL 打开对应官网；地址未识别或选择 LM Studio 时禁用，不提供明文切换按钮。模型名称右侧可“获取模型列表”，使用当前地址与 Key 请求，点击模型即可填入。点击“保存并开始”后，该配置同时成为默认 AI 与划词/句子翻译引擎；直接进入或关闭引导不会改变已有默认引擎。

```sh
npm run build
npm run preview
```

构建后的 **`dist/` 是完整静态站点**，可以部署到 Cloudflare Pages、GitHub Pages、Nginx 或任意静态 HTTP(S) 服务。Cloudflare Pages 构建命令为 `npm run build`，输出目录为 `dist`。不需要服务器数据库、Python、Node 后端或私有代理。不要直接以 `file://` 打开 HTML；浏览器的模块、Worker 和存储需要 HTTP(S) 环境。

所有浏览器统一使用同版本 PDF.js 官方兼容构建与配套 Worker，按实际缺失情况补齐所需 JavaScript 能力，避免 Chrome/Edge 等较旧内核因缺少 `getOrInsertComputed` 而出现 PDF 白屏。iPhone、iPad 和 macOS Safari 的文字选择、触控编辑和比例菜单规则仍在独立文件中；使用 iOS/iPadOS 浏览器时，长按 PDF 文字可选词，文本框工具在页面松手后创建输入框。

## 阅读与编辑

环形进度提示统一为约 1.2 秒一圈；系统启用“减少动态效果”时使用约 1.8 秒一圈，避免原来的极短时长导致异常高速旋转。

- 点击阅读栏右上“打开 PDF”，在按钮下方选择“本地文件”“APP 文档库”或“外部链接”。本地支持多文件导入；文档库窗口以可折叠文件树列出已有 PDF，点击文件打开。拖入 PDF 或按 `Ctrl / ⌘ + O` 仍直接导入本地文件。支持多标签切换，标签为紧凑单行；切换尚未完成时，后续点击不会打断首次操作。
- 移动端/窄屏（≤960px）顶栏显示“纸间 · 文献翻译”，使用顶栏右侧打开按钮；文件切换卡片右侧的重复打开按钮隐藏。桌面/宽屏保留原有布局。
- “外部链接”接受指向 PDF 数据的 HTTP(S) 完整地址，不再要求 `.pdf` 后缀，支持 arXiv 的 `/pdf/论文编号`、带查询参数及重定向的链接。可填写重命名名称，右侧固定 `.pdf` 后缀不可修改；留空沿用 URL 末段名称并补齐后缀。浏览器直接读取响应到内存，验证成功后打开并保存到文档库**根目录**，不先下载文件到本地目录，也不要求再次上传。关闭加载窗口会取消请求，失败或返回普通 HTML 网页不会入库。静态网页直接访问目标网站，需要网站允许跨域访问；HTTPS 页面还受浏览器混合内容限制。
- 文档、阅读页码、缩放比例、批注、全文译文和 AI 历史保存在浏览器 IndexedDB。关闭标签不会删除文档。“文档管理”提供搜索、重命名、重新打开和编辑后 PDF 下载。
- 本地选择、拖放和外链导入都会按原始 PDF 字节计算并保存初始 MD5。若文件库已存在相同 MD5，会询问“该文件已经存在于文件库中，是否继续上传？”；选“否”或关闭窗口只跳过这一份，选“是”则以“原名副本.pdf”创建新文档。副本有独立的编辑、对话和阅读状态，不与已有文件共享历史。文件名不同也会检测，相同文件名但内容不同可正常导入。
- 工具栏依次提供：缩略图、书签；比例、缩小、放大；页码、前后页；下划线、删除线、高亮、批注、文本框；形状、手绘笔、笔迹橡皮擦。后方还有撤销、重做、查找、带批注导出。窄屏可横向滚动工具栏。
- 比例菜单固定为“适应宽度、50%、75%、100%、125%、150%、200%”。通过减号/加号调整得到的非标准比例仍实时显示并保存，但不会新增到菜单选项中。选择器与展开菜单宽度不随文字长度变化，仍按 rem 和桌面/移动布局适配页面尺寸。
- **下划线、删除线、高亮、批注先选文字再点击**：无选区时不执行；所选内容未包含该标记时，点击添加一次并自动释放按钮。重新选中已有标记的文字时，对应按钮显示按下状态；再次点击清除该选区内的对应标记，保留其他类型以及选区外的部分。批注也会关联选中的文字，跨页操作可一次撤销。
- 文本框、形状、手绘笔和橡皮擦使用持续工具模式，点击同一工具退出；`Esc` 回到文字选择。高亮、批注、文本框、形状、手绘笔旁的小箭头打开对应菜单。形状菜单打开时，在菜单外的 PDF 浏览编辑区按下即收起菜单并激活当前形状；按下后继续拖动即可画出第一笔。
- 切换到文本框、形状、手绘笔或橡皮擦，以及开始编辑/拖动这些对象时，会清除已有的 PDF 文字选区；这些绘图操作不会再次触发先前选中文字的翻译。
- 批注/文本框菜单中，颜色下方的自绘滑块控制**后续新增内容**的字体尺寸（6–48 pt）；手绘菜单滑块控制后续笔迹粗细（0.5–12 pt）。当前值显示在右侧，偏好会保存；不批量改变已存在的标记。
- 形状菜单可选矩形、圆形、直线、箭头及颜色；选择形状立即激活绘制模式，工具栏图标同步变为该形状，在页面拖动并松手完成绘制。再次点击形状工具或按 Esc 退出。形状为彩色轮廓，可撤销/重做，随文档和备份保存，并写入导出的 PDF。圆形按拖动范围短边确定直径，保持正圆。
- 高亮使用浅色半透明正片叠底；批注和文本框改为原位输入，单击调整尺寸，双击修改文字，也可按住拖动到本页其他位置，形状同样支持鼠标或触控拖动。松手保存新位置，取消手势恢复原位；移动不会修改批注关联的原文选区。
- 橡皮擦按住鼠标或触控后可从空白处开始拖动，沿移动轨迹连续擦除本页多条笔迹和多个形状；快速滑过也按两次事件之间的完整路径检测。松开、取消触控或失去指针捕获后停止，悬停不擦除；批注、文本框和文字标记不受影响。每个被擦除对象可单独撤销，删除实时保存。`Ctrl / ⌘ + Z` 撤销当前会话操作，`Ctrl / ⌘ + Shift + Z` 重做；撤销/重做自动定位对应页面与对象，无可用历史时按钮变灰且不可点。
- 页面只渲染可见区域附近内容，远处画布释放；低于 100% 缩放也使用较高分辨率重新渲染，文字选择层保持对应位置，单页像素预算仍受控。原始 PDF 不被覆盖。带批注下载会生成新 PDF：批注、下划线、删除线、高亮和笔迹保存为标准 PDF 注释，文本框与形状按其显示写入页面。保存期间防止重复点击；取消或写入失败不会再次弹窗另存一份。**不支持重排或直接修改 PDF 已有正文**，编辑范围为标注、添加文本和手绘。
- 文字层先在页面外构建，再一次挂载；文字宽度测量与位置更新分批执行，避免片段密集的论文在滚动时反复重排、冻结界面。保留原始清晰度、字体及选区对齐，不将文字转成不可选择的图片。
- PDF 自带的文献引用、图表编号等内部链接支持短按鼠标或触控跳转，并按目标页及坐标定位；悬停有轻微提示，也可用键盘聚焦后 Enter。链接位置随缩放、旋转和裁切同步；拖选文字、长按及批注/绘图操作保持原行为。只有 PDF 本身包含内部链接时才可跳转，不自动推测普通文字编号。
- 加密 PDF 会要求输入密码。密码不保存在存档中；加密文件的批注导出受 pdf-lib 的加密限制，失败时原文件与批注数据仍保留。

### 原位批注与文本框

批注或文本框下方浮动工具栏的字号增减，同时更新该类对象的默认字号并自动保存。两类分别记忆，输入/尺寸编辑模式均适用；后续新建同类对象沿用该值，工具栏菜单中的字号滑块同步显示最新尺寸。浮动按钮和滑块均限定在 **6–48 pt**，已有其他对象不被批量改字号。

- 建立批注仍先选择 PDF 文字再点“批注”；建立文本框在页面点击放置。直接在原位置的框中输入，Enter 换行，不再打开输入弹窗；点击框外结束编辑，输入实时保存。未填写内容或清空全部内容后结束编辑，空对象自动移除。
- 单击已有对象进入尺寸模式：左右圆点调整宽度，上方移动手柄及对象主体可拖动；双击（手机双点）进入文字编辑。
- 默认随文本自动调整宽高，自动宽度上限沿用页面宽度的 45%。手动改宽后，后续文字编辑保持该宽度，只调整高度并自动换行；手动宽度可超过 45%，仍限制在页面范围内。
- 尺寸模式下，对象下方浮动图标依次为字号增大、字号减小、文本框边框开关（批注无此项）、尺寸重置和红色删除。尺寸重置解除手动宽度、恢复自动排版，保留字号和样式；删除无确认窗口，可用撤销恢复。浮栏直接随对象同步移动，并约束在阅读区域内。
- 文字编辑模式下也显示浮栏，仅保留字号增大、字号减小、红色删除三个按钮。点击字号按钮保持输入焦点，修改即时保存；删除可撤销恢复刚才编辑的内容。
- 批注关联文字显示同色下划线，悬停原文时批注轻微发光。此下划线属于批注，删除批注会一并消失，独立添加的普通下划线不受影响。
- 宽度、边框、字号和多行文字均随存档保存。导出/备份等待正在进行的批注写入完成；文字编辑以一次会话合并到撤销历史，尺寸和浮动工具操作分别可撤销。

导出时，文字关联批注使用标准 Underline + Popup，无文字锚点的旧便签使用 Text + Popup，正文不会混入批注内容；原有 PDF 注释也会保留。文本框继续作为页面文字导出，并保留换行与可选边框。

普通下划线、删除线、高亮分别保存为 Underline、StrikeOut、Highlight 标记。一笔连续手绘保存为一个 Ink 铅笔注释，整笔坐标保存在同一对象中，支持具备注释编辑能力的阅读器整体移动或擦除；不再拆成页面散点。高亮保留浅色透明效果，具体编辑入口由阅读器提供。

v0.3.1 修复 Noto 字体子集编码，保留原始 NotoSansSC 字体和字形；导出后再次编辑、导出不会替换字体。对旧版应用导出中可识别的损坏子集，在再次导出时从同一原始字体恢复，保留原字符映射。

**阅读器兼容性：** PDF.js、MuPDF 已验证完整的中文、多行批注和弹窗关联；Chrome 自带阅读器已实测能悬停弹出批注，但当前版本的弹窗固定使用 ANSI 字体，中文可能漏显，PDF 内的 Unicode 内容仍完整。此限制来自 Chrome/PDFium 的弹窗生成方式，查看中文可使用支持完整注释显示的阅读器；本轮未运行 Acrobat，不能宣称已逐版本实测。来源说明见 THIRD_PARTY.md。

### PDF 导航与查找

搜索结果的浅黄色高亮仅在“查找”页签打开时显示。关闭 PDF 导航栏或切换到“书签”“缩略图”会立即隐藏高亮；再次进入查找页签恢复原结果，不需要重新搜索。用户自行添加的高亮、下划线和批注不受影响。

点击“缩略图”“书签”或“查找”打开统一 PDF 导航栏，顶部的“书签 | 缩略图 | 查找”页签可以快速切换。桌面上导航栏位于功能侧栏与阅读栏之间，功能侧栏收窄为 Logo 和 6 个图标，适应宽度随阅读区域调整；点击已激活导航按钮或关闭按钮恢复布局。

**移动端/窄屏始终保留底部功能导航**，不会新增左侧功能栏。PDF 导航以阅读区上的浮窗展示，不压缩 PDF 宽度、不改变当前缩放；点击浮窗外任意位置可关闭。

缩略图每行一页、按需渲染，点击跳页；书签读取 PDF 内置目录，支持嵌套目录及命名目标，点击跳至对应页。没有书签的 PDF 显示空状态。此入口不创建用户自定义书签；无文档内目标的外部书签不会自动打开网址。切换文档时导航内容同步切换。

查找页提供文本输入、查找按钮、“区分大小写”和“全字匹配”开关。点击查找或按 Enter 后扫描全部页面，过程中显示环形进度；所有结果逐行列出，悬停可查看完整摘要，点击定位到实际命中文字。命中使用浅黄色高亮，缩放后重绘；搜索标记不写入批注、PDF 文件或备份。清空输入并查找可移除结果，切换 PDF 自动清除旧文档结果。

文字层与画布统一使用 PDF 字体、页面旋转、裁切框和页面单位；按实际 DOM 字宽校正文字段，并补齐精确尺寸与旋转规则。0.1.3 的对齐回归覆盖 25%–400% 缩放、部分单词、旋转/裁切页及高 DPI 嵌入中文字体。

## 文档管理：文件夹与批量操作

- 从 PDF 阅读页面进入“文档管理”，自动显示当前正在阅读的 PDF 所在目录，并清除先前的搜索/选择状态；文件已被移动时使用最新目录。没有打开任何 PDF 时进入根目录。桌面侧栏和移动端底栏行为一致，文档管理页面内的目录浏览与排序偏好继续保留。
- 点击“新建文件夹”，可在当前目录建立任意层级的子文件夹；点击文件夹进入，通过路径栏返回父目录或根目录。在文档管理中导入 PDF 会保存到当前目录。
- PDF 和文件夹卡片左上角都可多选。选中后，“导入 PDF”左侧出现浅色“移动”“下载”和红色“删除”按钮。切换目录或修改搜索时会清空选择，避免对不可见对象误操作。
- 移动窗口展示内部文件树，根目录及子文件夹均可作为目标；也可在当前选中的目标目录下直接新建子文件夹。不能把文件夹移入自身或后代；同时选中父目录和子项目时保留层级，不重复移动。
- 移动原文（包括移动其所在文件夹）时，所有关联译文自动与原文归入同一目录。单独移动译文不会反向移动原文。新生成的译文按生成时原文的最新目录入库。
- 下载仅包含选中的对象及选中文件夹的后代，不自动附带未选中的原文或译文。单个 PDF 下载为 PDF；两个 PDF 分别保存；超过两个 PDF 或选中任何文件夹时生成 ZIP。ZIP 包含选中文件夹本身、空子目录和各层 PDF，保留层级；重复文件名会加序号，避免覆盖。
- 所有 PDF 下载入口（阅读工具栏、文档管理单份/两份/ZIP、已生成的译文 PDF）都会导出该文件当前未删除的编辑；批注、文字标记、笔迹作为标准注释保留，文本框及形状写入页面。源 PDF 与可继续编辑的记录保持独立；完整备份仍同时包含源文件和全部编辑状态。
- 卡片/列表视图、按名称/导入时间、正序/倒序均可切换并记住偏好；文件夹始终在文件前。搜索范围为当前目录。

删除前会列出实际对象及路径并要求确认。仅删除确认范围内的 PDF、对应编辑记录和可安全移除的目录；确认期间新增的内容、已移出选中目录的文件不被扩大纳入，含剩余内容的文件夹会保留。**未选中的配对原文/译文不会联动删除**；只要同组仍有一份文件，所有共享 LLM 对话和全文翻译历史继续保留，问答使用仍存在的文件作为上下文。组内最后一份文件被删除时，才删除该组共享历史。

删除是不可撤销的文档管理操作，请在需要时先备份。删除标记会随存档/同步保存以阻止旧云快照复活已删除内容；遇到较新的本地编辑时优先保留。用户主动导入本地旧备份可恢复其中的已删除对象。

初始 MD5 仅来自入库前的原始文件，批注、重命名和移动不会改变它。旧文档缺少此字段时，在重复检测中从原始文件异步补算；MD5 随现有存档和云同步保存。通过全文翻译自动生成的 PDF 同样记录自身 MD5，并继续遵循原文/译文共享对话的规则；手动重新上传相同文件则始终创建独立文档。

### 下载位置

支持文件/目录选择器的浏览器会在点击后立即选址，再加载导出模块或生成文件；一次下载不重复选址。两份独立 PDF 共用一次目录选择。取消选址不下载，写入失败也不另行重试下载。

**不支持保存位置选择器的浏览器直接下载到默认位置，不额外提示。** 浏览器自己的多文件下载许可和保存偏好仍由浏览器控制。

## 划词、句子与段落翻译

“原文”和“翻译结果”（包括词典释义）标题右侧，在朗读/复制按钮前提供字号缩小、加大按钮。两块内容分别记忆字号；“全文翻译”结果的“复制全文”左侧也有独立字号按钮。每次调整为默认字号的 10 个百分点，范围 70%–180%；达到边界时对应按钮变灰并禁用。字号即时保存到 APP 配置，切换论文、刷新、再次启动及恢复设置后保留，不触发新的翻译请求。

字号调整仅影响相应阅读区域，Markdown 标题、表格、代码、公式和词典内容随之缩放，保留原有层级和颜色；复制文本与导出 PDF 的排版规则不因阅读字号改变。三项偏好随普通备份和云同步保存，导入存档时勾选“同时恢复设置”可恢复。

在 PDF 中选择文本，**松开鼠标或触控后**才发起翻译；拖动尚未结束时仅更新选区/标记状态，不调用词典或翻译 API。从原文开始取词后，直到松手前，批注、文本框、形状和笔迹不再参与鼠标/触控交互，可以连续选择其覆盖的文字；正常直接按住元素仍可拖动。键盘选区也支持在选择快捷键释放后提交。选择离线引擎时，单词与句子均本机翻译；其他引擎下英文单词走在线词典，不调用 LLM。Free Dictionary 与 Wiktionary 英文词典并行请求，优先显示可用释义，中文释义和词形也独立加载，避免一个站点超时阻塞所有结果。词性、音标、例句、近义词、词形以实际词条提供的内容为准；仅中文释义可用时明确显示详细词典未连接，不编造缺失内容。原文区域使用较紧凑的字号和行距。

中文简短词义优先沿用现有基础翻译服务。只有简短词义、空词性或空解释不算获取到详细释义；缺少中文或详细释义时，依次查询 [FreeDictionaryAPI.com](https://freedictionaryapi.com/)、[3325 词典](https://3325.cn/api-docs)，补齐后停止，全部候选失败才结束尝试。切换选词会取消旧查询。两家均无需 Key，直接从浏览器调用，可能受网络或限流影响。

英文详细解释先通过基础翻译 API 转成中文再显示，常见词性统一显示中文名称；音标、原文例句、近义词和词形保留词典数据。优先使用当前基础翻译服务，失败时尝试其他免 Key 或已完整配置的基础服务，网页版跳过明确不支持的方式；此过程不调用 LLM、不改变默认设置。相同解释在本次查询中只翻译一次，结果注明翻译来源。翻译均失败时继续查询可直接返回中文详细释义的词典；仍无法获得时保留已有简短词义并如实提示，不把未转换的英文冒充中文显示。

**内置有道词典（网页版不支持）**：在已接入 CORS 代理的客户端中优先调用有道 suggest 接口，将解释中的 `n.`、`v.`、`adj.` 等词性拆成独立释义。网页版自动跳过，不发起有道请求；客户端请求失败或缺少详细释义时继续普通词典流程。设置 → 基础翻译功能中也有适用范围说明。当前交付已包含请求与解析逻辑，轻量 CORS 代理按后续客户端打包计划接入；接口返回的省略内容不会自行补写。

备选返回的音标、词性和释义适配同一词典面板；FreeDictionaryAPI 还提供例句、近义词和词形。已获取的主要词典释义保留，缺失的音标和新增词形可补充显示；没有返回的发音音频或词形不会编造。FreeDictionaryAPI 的中文来自词义中的中文翻译，保留原有简繁文字；结果中显示其署名、原始 Wiktionary 词条及返回的 CC BY-SA 许可证链接，3325 显示对应词条来源。

多个词或整段文字使用所选翻译引擎，未配置 AI 时初始为无需 Key 的 MyMemory。在“划词翻译”页，右上设置图标左侧直接显示引擎 LOGO 与“·机翻 / ·AI”，空间较窄时仅显示 LOGO。点击后按“机翻高速引擎 / AI 大模型引擎”分组列出预置、已配置的基础 API 和全部 LLM API；选择后立即保存，不改变默认问答 API。MyMemory 按界面要求使用彩色 Meta 图标，此图标不表示服务归属于 Meta。

划词页的“翻译设置”仅保留原文语言、目标语言和翻译风格；切换到“全文翻译”或“AI 问答”后，顶部引擎图标隐藏，引擎下拉回到翻译设置浮层原位置。全文翻译/问答各自的任务 API 选择规则不变。百度基础翻译同样使用风格项选择接口。默认风格为学术论文，也可改为直译、通俗解释或技术文档。

本地清洗处理跨行断词、连续页边行号、引用标记和空白；保留年份、数字和数学上标。LLM 提示额外要求识别脚注、尾注、页眉页脚等排版噪声。复杂双栏、脚注串入正文等情况仍可能需要人工核对。划词结果仅保存在当前页面内存中，不进入备份。

免费在线服务需要互联网、可能限流，并受所在地网络条件影响；它们不是应用内置的离线翻译模型。原文语言默认英文，可在设置中修改。

## 基础翻译功能（不调用 LLM）

打开“设置 → 基础翻译功能”。标题下的“默认基础翻译模型”自绘下拉包含预置 Lite、已下载/导入的离线模型、MyMemory（每日上限低）、Google 翻译（仅海外可访问），以及已完整填写并保存凭据的其他 API；选择后自动保存。阅读区引擎选择也列出这些服务及已有 LLM，选择基础引擎会同步更新基础翻译默认值，保留原 LLM 默认配置。

### 本地离线翻译模型

“本地离线翻译模型”位于百度 API 上方，默认折叠。展开后每个模型各占一行，显示模型占用、状态和图标按钮；手机端操作按钮换至该行下部，避免拥挤。

| 栏目 | 实际模型与语言方向 | 模型文件占用 | 获取方式 |
| --- | --- | --- | --- |
| 中英翻译 Lite | Firefox Release `en→zh base-memory`，英文 → 简体中文 | 47.6 MiB | 随静态站点预置，不可删除 |
| 中英翻译 Plus | `Xenova/opus-mt-en-zh` INT8，英文 → 简体中文 | 114.0 MiB | 从 ModelScope 下载或导入；可删除 |
| 多语种翻译 Pro | `Xenova/nllb-200-distilled-600M` INT8（ModelScope） | 869.7 MiB | 下载或导入；可删除；CC-BY-NC-4.0，仅限非商业用途 |

以上为完整所需权重、配置和词表大小，另有约 24 MiB 共享推理运行库。Pro 支持当前菜单中的简中、繁中、英、日、韩、法、德、西八种语言，需明确选择原文语言；“中英翻译”是栏目名称，Lite/Plus **不支持中文→英文**。Pro 的运行内存明显高于文件大小，优先在内存充足的电脑上使用；手机、平板建议 Lite。三者是机器翻译模型，不具备聊天或执行提示词能力，也不保证每篇论文的术语准确。

1. 进入 APP 先加载界面。当前引擎是在线 API 或 LLM 时，Lite/Plus/Pro 都不加载，也不自动请求其权重和 WASM/ONNX 运行库。若上次已选中某个本地引擎，页面可操作后只在 Worker 中准备该模型；其他模型不加载。
2. 在右栏“翻译引擎”选择本地模型后，会后台加载并保持待用；模型加载不阻塞设置、PDF 阅读或其他 API。加载未完成就划词，结果区显示“离线机翻模型加载中”，准备完成后显示“正在理解这段文字…”。切换到其他本地模型、在线 API 或 LLM，会立即终止旧模型 Worker（包括加载中的任务），释放其运行内存；模型文件仍留在本地，下次选中可从缓存重载。
3. Plus 和 Pro 均从 ModelScope 的固定版本下载，不使用存在浏览器 CORS 限制的回退站点。所有文件通过大小与 SHA-256 校验后，才显示“已下载”、替换为“删除”按钮并加入下拉菜单。下载失败保留已校验文件供重试；“取消”会终止下载 Worker，事务删除该模型已下载的文件和安装标记；不清空数据库，不更改 PDF、批注、聊天、密钥或其他设置，其他模型和共享运行库保留。
4. 无法访问 ModelScope 时，可在其他设备按清单下载并点“导入”：Plus、Pro 分别选择各自的六个文件：`config.json`、`generation_config.json`、`tokenizer.json`、`tokenizer_config.json`、`encoder_model_quantized.onnx`、`decoder_model_merged_quantized.onnx`。无需 Python 转换；`.gz` 会自动解压校验。不同版本、其他精度、PyTorch 权重或任意自定义模型不能冒充当前模型导入。
5. 在默认基础翻译下拉或右上“翻译引擎 → 机翻高速引擎”中选择离线模型，使用彩色本地电脑图标，并在主界面下拉中显示“本地引擎 · 模型名”。单词与句子均走本机推理，不请求在线词典；在线引擎原有词典行为不变。删除正在选用的 Plus/Pro 会将基础默认值切回 Lite。

模型数据独立保存在 `paper-bridge-offline` 数据库，删除模型不会删除 PDF、批注、聊天、API Key 或其他设置。模型权重不包含在用户备份/云同步中；更换设备需重新下载或导入，备份中的默认模型偏好仍保留。浏览器主动清理站点数据、隐私模式及磁盘配额可能清除或拒绝缓存，网页不能保证模型永远不被系统回收。

### 离线部署与浏览器条件

`dist/` 仅预置 Lite 和推理运行库，Plus/Pro 权重不随包分发，部署包仍约 89.4 MiB。Lite 在浏览器中只读取同源静态资源，不依赖大陆网络访问 Mozilla 或 Google 下载站；离线本地部署直接使用随包文件。Lite 原始 `.gz` 在构建准备阶段解压，最大权重拆成 16 MiB 片段，模型不进入 JavaScript bundle。准备脚本只在文件缺失或损坏时尝试固定镜像和官方源，逐源解压并校验；这些构建期来源不作为浏览器跨域模型下载接口。

- **静态网站**：通过 HTTPS 或 `localhost/127.0.0.1` 打开生产构建，首次在线完成页面静态资源缓存后即可断网打开界面，无需等待 Lite。要离线翻译，需先选中相应本地模型完成一次准备；Plus/Pro 也可显式下载或导入。Service Worker 安装时不预缓存 Bergamot/ONNX 运行库，运行库只在选中模型或显式下载/导入时进入独立按需缓存，权重仍由独立 IndexedDB 保存；开发模式不注册 Service Worker。网站更新会等待旧标签关闭后激活，升级只清理本应用旧静态缓存。
- **无外网本地部署**：在电脑上用本地静态服务提供整个 `dist/`；Tauri 可使用 `frontendDist: "../dist"` 将同一目录随包携带，Lite 在被选中时从包内资源准备，不需先联网。Plus/Pro 可通过文件导入。不要只复制 `index.html`，也不要使用 `file://` 双击运行。
- **Tauri 宿主**：需使用支持模块 Worker、WebAssembly、IndexedDB 的系统 WebView；静态协议需正确提供 JS/MJS/WASM MIME 类型。如果宿主启用 CSP，须允许本地 Worker、模块、WASM 编译与静态资源请求；无需 WebGPU、SharedArrayBuffer 或 COOP/COEP。Service Worker 不可用的自定义协议仍可读取随包资源。本项目未新增原生工程、未制作或真机验证 Tauri 安装包。
- **兼容性**：CPU 单线程 Worker，在支持相应 WASM 能力的现代 Chrome/Edge、Firefox、Safari/WebView 上运行。Mozilla 预编译 Bergamot 包含 SIMD/原子指令，不能声称是无 SIMD 的最低版本 WASM；启动前会检测模块能力，不支持时明确报错。ONNX 使用支持标量回退的固定浏览器运行库。不承诺所有历史浏览器、低内存设备均能加载 Pro；不支持时可使用 Lite 或升级浏览器。

本轮遵循“不增加部署包、不使用 CORS 受限站点”的约束：未找到满足条件的 Firefox `en→zh base` 浏览器下载源，因此 Plus 保留原 OPUS-MT INT8。曾考虑的 Plus 静态权重已移除，不需要重新安装已有 OPUS/NLLB 缓存。ModelScope 连接和 CORS 已在本开发网络实测，仍可能受具体运营商、浏览器策略或服务可用性影响。

本次验证包含：从 ModelScope 实际下载完整 OPUS-MT 后翻译、NLLB 文件哈希/跨域读取、取消 Plus/Pro 时个人数据保留，以及三模型准备完成后关闭源站再重载翻译。可选联网回归需设置 `PAPER_BRIDGE_TEST_LIVE_SOURCES=1`；默认不会为了测试重新下载模型。

Lite 按 **2026-09-25** Mozilla Release 注册表固定为 `llmaat_finetune10M_qe8_f2_ByQcSxGXQRqGi-UTxYE43g`，后续上游更新不会自动替换权重。完整来源、许可证与运行库适配记录见 [THIRD_PARTY.md](THIRD_PARTY.md)。

已验证 Chrome 153、Firefox 155、WebKit 26.6 的生产 Lite 离线重载，Chrome 还验证了 Plus/Pro 断网推理。Windows Playwright 提供的旧 WebKit 18.4 能执行 Lite 推理，但其 CacheStorage 写入探针返回空，未通过断网重载；此环境应保留本地静态服务或升级内核，不视为 Safari 真机结论。

三家云服务默认折叠为单行。点击展开后可查看教程、填写账号与密钥，使用眼睛图标切换密钥显示，填写内容会实时自动保存，无需额外点击，也不会弹出自动保存提示。可用“连接测试”验证一条短句，或用“保存配置”主动确认保存。教程链接在浏览器新标签页打开；已有 Tauri 宿主可使用系统浏览器桥接。

| 服务 | 配置字段 | 使用方式 |
| --- | --- | --- |
| MyMemory | 无 | 即开即用，每日限额较低 |
| Google 翻译 | 无 | 直接调用 Google 在线翻译端点，需要能访问 Google 的网络 |
| 百度论文翻译 API（每月 50 万字符免费额度） | APP ID、密钥 | “学术论文”使用领域接口、domain=academic；其他风格使用通用接口 |
| 阿里云翻译 API（每月 100 万字符免费额度） | AccessKey ID、AccessKey Secret | 通用版 TranslateGeneral，文本模式、general 场景 |
| 火山引擎翻译 API（每月 200 万字符免费额度） | AccessKeyID、SecretAccessKey | TranslateText，按官方 cn-north-1 地域签名 |

百度学术领域仅支持简体中文与英文互译，其他语言方向需修改风格或更换服务。单词仍查询在线词典，按上述流程补齐中文词义与详细释义；百度的单词释义及英文解释翻译走通用接口。全文翻译及 AI 问答继续使用 LLM。

绿点“可连接”表示当前填写配置最近一次测试成功；仅填写凭据不会显示绿点。更改凭据会取消在途测试并重置状态，旧请求返回成功也不会覆盖新输入；测试成功状态和时间也会自动保存。测试按当前翻译风格执行，额度和认证条件以服务商控制台为准。

所有请求直接发送到所选服务的官方域名，无额外后端。百度使用官方支持的 JSONP 回调解决跨域，阿里云/火山使用带签名的 HTTPS 请求；超时、鉴权失败、额度不足或跨域拒绝会报告错误，不偷偷切换到 LLM。若部署了额外 CSP，需允许百度官方 API 的脚本回调。火山部分鉴权失败响应可能缺少跨域许可，此时浏览器只能报告连接失败。

账号 ID 与密钥只在本地设置中保存。未勾选“包含 API Key 与云凭据”的备份和云同步会移除这些凭据；完整备份可恢复。导入无凭据存档不会清空已有本地凭据，也不会把不同账号的 ID 与旧密钥拼在一起。

## 全文翻译与 PDF 输出

打开文档 → 右栏“全文翻译” → 选择目标语言、API 和展示方式 → “开始全文翻译”。

| 模式 | 实际行为 |
| --- | --- |
| API 支持 PDF 输入 | 以完整 PDF 的 Base64 文件内容发送给所选模型；模型须支持该接口的文件输入 |
| 普通文本 API | 浏览器提取全部页面文字后发送，不静默截断；扫描 PDF 需改用支持文件输入的视觉模型 |
| 直接展示 | 流式接收 Markdown，渲染标题、段落、粗斜体、字体颜色、KaTeX 行内/块公式、代码高亮、表格和安全内嵌样式；图片以占位描述表示 |
| 本地排版生成 PDF | 将完整译文按页面排版后生成 PDF，可下载或在左侧打开；此导出为视觉版 PDF，文字、公式、表格被栅格化，不提供可搜索文字层，也不复刻原 PDF 版式 |
| 模型直接生成 PDF | 通过 Responses + Code Interpreter 请求真正的 PDF 文件，读取容器文件引用并下载；只有明确支持文件输出的服务可用，不把普通文本伪装成 PDF |

圆环进度按真实请求阶段显示 PDF 上传中、LLM 分析中、结果转换中。停止或网络中断时保留已收到内容；服务端长度限制会作为未完成结果明确显示。应用不设置 `max_tokens` 强制截断输出。全文与完整历史可能超过所选模型的上下文限制，此时需选择更大上下文模型。

首段全文译文到达时，顶部参数区会动画折叠为一行“结果转换中”状态栏；滚动译文时状态栏保持吸顶。点击右侧箭头可重新展开，后续输出不会强制收起已手动展开的参数。状态栏也提供停止操作，完成后保留译文展示空间。

长译文的接收、保存和显示分别调度：合并高频输出，使用本地 Worker 解析 Markdown/公式，复用已经显示的段落和长段内部片段，减少全文重复排版。新块先在页面外构建再一次挂载；渲染完成或离开全文页后释放 Worker。浏览时支持的浏览器会跳过屏幕外内容的绘制；未支持该优化的浏览器仍正常显示。全文内容不截断，复制和导出仍使用完整原始译文。

全文译文约每 200 毫秒合并保存最新内容；完成、停止、失败及导出备份时等待最后写入，切换后台也主动刷新。显示通常按约 80 毫秒合并更新，不排队逐字回放旧片段；实际延迟仍取决于设备、公式/HTML 复杂度和浏览器。突然强制结束浏览器仍只能恢复已经落盘的部分。

PDF 文件输入优先采用所选协议的标准格式；若 Chat 兼容网关明确返回 `file must have a file_id or file_data`，会携带相同完整 PDF 按扁平文件字段兼容重试一次。其他 400 错误不盲目重试，也不会悄悄降级成文本。模型是否能处理 PDF 仍取决于服务商能力。

翻译后 PDF 会保存为单独文档，并与原文共享 AI 对话。浏览器支持文件选择器时，可指定保存位置，否则使用浏览器默认下载流程。

点击“在左侧打开译文 PDF”开始转换时，该按钮显示与现有图标一致的旋转进度图标并暂时禁用，转换、入库和打开完成后恢复；失败时也会恢复，允许重试。

## AI 问答

- 问答使用当前 PDF 的完整文字或文件以及所选对话的全部先前消息；不会按固定轮数裁剪。
- 可新建多个独立对话、重命名、切换历史并继续提问。切换 PDF 会切换关联历史；原文与翻译后 PDF 共享同一组历史。
- 用户消息先写入 IndexedDB，再发出网络请求；流式每个增量先提交存储，再显示。停止、请求失败或刷新后保留已经成功落盘的内容。
- `Enter` 发送，`Shift + Enter` 换行。流式生成期间可停止，也可以切换到其他文档继续阅读。
- 提交问题后、首段回答到达前，助手消息里显示“正在思考”环形动画；开始输出后由回答替换，停止或失败后移除。恢复旧的未完成记录时不会假装后台仍在思考。
- 已关闭应用后尚未从网络接收的数据无法保存；浏览器强制终止、磁盘故障或主动清理站点数据也无法由网页绝对保证恢复。请使用备份和云同步。

## 备份与云同步

“设置 → 备份与存档”可以导出 ZIP，包含所有 PDF、编辑记录、全文译文、对话和界面设置；API Key 与云凭据默认不包含，可显式勾选。

勾选“包含 API Key 和云同步凭据”后，存档会包含所有 LLM 配置的 Key、地址、模型与能力选项，三家基础翻译的账号 ID/Secret，WebDAV 账号/密码及其他已配置偏好。导出前会等待正在进行的自动保存完成，避免遗漏最后一次输入；不勾选时仍会剥除凭据。输入备份密码则生成 AES-GCM 加密的 `.pbak`，密码不写入存档。

0.2.0 的完整备份还包含文件夹、目录关系及精确删除标记。数据库自动从版本 1 增量升级到版本 2，保留已有记录；旧文档默认位于根目录。仍可导入旧版存档，旧版应用不能读取新的版本 2 存档。如升级等待其他窗口关闭，关闭旧版本标签页后重新打开即可，不需要清空站点数据。

导入前检查版本、记录引用和每个 PDF 的 SHA-256；校验通过后用单个 IndexedDB 事务合并。导入不清空现有库。冲突消息、译文或批注保留恢复副本；对话界面会标注恢复副本。可选择恢复设置并合并 API，缺省空密钥不会覆盖本机已有密钥。请妥善保管加密备份密码。

“设置 → 云同步”配置 WebDAV 地址、目录、账号和应用密码后，可测试连接或立即同步，也可启用应用打开期间每 30 分钟自动同步。流程为读取云端 → 校验 → 合并本地 → 条件上传；不删除云文件。云端不携带 API Key 和 WebDAV 凭据，设备连接设置不会被自动恢复。

WebDAV 必须支持 HTTPS（HTTPS 网页不能访问普通 HTTP 服务）、CORS、`GET / PUT / MKCOL / PROPFIND`、条件请求 `If-Match / If-None-Match`，且通过 `Access-Control-Expose-Headers: ETag` 暴露强 ETag。远端更新导致 `412` 时停止覆盖，保留本地合并结果，重新同步即可。

“永久保存”是浏览器允许范围内的持久化：应用会请求 Storage Persistence，但配额、隐私模式、用户清除站点数据等仍由浏览器控制。浏览器的不同域名、端口、配置文件彼此隔离。

## 桌面与移动端

桌面使用侧栏、PDF 栏、翻译栏三部分，分栏宽度可拖动或键盘调整。移动端使用底部导航，在阅读、翻译/AI、文档管理之间分屏切换；不会将两个主栏叠在一起。手机选词后留在阅读页，便于继续点选批注工具；译文仍自动请求，可点击底栏查看。单行文件卡片保留约 44px 的触控高度。两套交互和样式分别位于 `src/js/ui/desktop.js`、`src/js/ui/mobile.js`、`src/styles/desktop.css` 和 `src/styles/mobile.css`。

构建产物不依赖操作系统，可在 Windows/Linux/macOS/Android/iOS 的现代浏览器运行，并可作为 Tauri 的 `frontendDist`。**当前交付是静态 Web 应用，尚未制作或验证 Tauri 安装包。** “获取”官网入口已适配 Tauri 系统浏览器桥接：Tauri 2 打包时需启用 opener 插件及对应 URL 打开权限，也兼容已有 Tauri 1 shell.open；默认浏览器的最终标签策略由系统/浏览器控制。
