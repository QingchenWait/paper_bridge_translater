# 纸间 · Paper Bridge

一个无需后端、可静态部署的 PDF 阅读与 AI 翻译应用。版本 **0.1.3**。

## 开始使用

需要 Node.js 22.13+（建议 24 LTS）。

```sh
npm install
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173`。首次启动可以配置 AI 服务，也可以选择“先使用在线翻译”，直接使用词典和句子翻译。

```sh
npm run build
npm run preview
```

构建后的 **`dist/` 是完整静态站点**，可以部署到 Cloudflare Pages、GitHub Pages、Nginx 或任意静态 HTTP(S) 服务。Cloudflare Pages 构建命令为 `npm run build`，输出目录为 `dist`。不需要服务器数据库、Python、Node 后端或私有代理。不要直接以 `file://` 打开 HTML；浏览器的模块、Worker 和存储需要 HTTP(S) 环境。

## 阅读与编辑

- 点击“打开 PDF”、拖入 PDF，或按 `Ctrl / ⌘ + O`。支持多文件导入、多标签切换；标签为紧凑单行，页码仅在工具栏显示。
- 文档、阅读页码、缩放比例、批注、全文译文和 AI 历史保存在浏览器 IndexedDB。关闭标签不会删除文档。“文档管理”提供搜索、重命名、重新打开和原文件下载。
- 工具栏依次提供：缩略图、书签；比例、放大、缩小；页码、前后页；下划线、删除线、高亮、批注、文本框；形状、手绘笔、笔迹橡皮擦。后方还有撤销、重做、查找、带批注导出。窄屏可横向滚动工具栏。
- **下划线、删除线、高亮、批注先选文字再点击**：无选区时不执行；所选内容未包含该标记时，点击添加一次并自动释放按钮。重新选中已有标记的文字时，对应按钮显示按下状态；再次点击清除该选区内的对应标记，保留其他类型以及选区外的部分。批注也会关联选中的文字，跨页操作可一次撤销。
- 文本框、形状、手绘笔和橡皮擦使用持续工具模式，点击同一工具退出；`Esc` 回到文字选择。高亮、批注、文本框、形状、手绘笔旁的小箭头打开对应菜单。
- 批注/文本框菜单中，颜色下方的自绘滑块控制**后续新增内容**的字体尺寸（6–48 pt）；手绘菜单滑块控制后续笔迹粗细（0.5–12 pt）。当前值显示在右侧，偏好会保存；不批量改变已存在的标记。
- 形状菜单可选矩形、圆形、直线、箭头及颜色；激活形状工具后，在页面拖动并松手完成绘制。形状为彩色轮廓，可撤销/重做，随文档和备份保存，并写入导出的 PDF。圆形按拖动范围短边确定直径，保持正圆。
- 高亮使用浅色半透明正片叠底；批注和文本框可点击编辑或删除，也可按住拖动到本页其他位置，形状同样支持鼠标或触控拖动。松手保存新位置，取消手势恢复原位；移动不会修改批注关联的原文选区。
- 橡皮擦可删除命中的整条笔迹或整个形状。`Ctrl / ⌘ + Z` 撤销当前会话操作，`Ctrl / ⌘ + Shift + Z` 重做；拖动、编辑和删除也可撤销。撤销/重做自动跳到对应页面和操作位置，无可用历史时按钮变灰且不可点。
- 页面只渲染可见区域附近内容，远处画布释放；低于 100% 缩放也使用较高分辨率重新渲染，文字选择层保持对应位置，单页像素预算仍受控。原始 PDF 不被覆盖。带批注下载会生成新 PDF，将编辑内容写入页面。保存期间防止重复点击；取消或写入失败不会再次弹窗另存一份。**不支持重排或直接修改 PDF 已有正文**，编辑范围为标注、添加文本和手绘。
- 加密 PDF 会要求输入密码。密码不保存在存档中；加密文件的批注导出受 pdf-lib 的加密限制，失败时原文件与批注数据仍保留。

### PDF 导航与查找

点击“缩略图”“书签”或“查找”打开统一 PDF 导航栏，顶部的“书签 | 缩略图 | 查找”页签可以快速切换。桌面上导航栏位于功能侧栏与阅读栏之间，功能侧栏收窄为 Logo 和 6 个图标，适应宽度随阅读区域调整；点击已激活导航按钮或关闭按钮恢复布局。

**移动端/窄屏始终保留底部功能导航**，不会新增左侧功能栏。PDF 导航以阅读区上的浮窗展示，不压缩 PDF 宽度、不改变当前缩放；点击浮窗外任意位置可关闭。

缩略图每行一页、按需渲染，点击跳页；书签读取 PDF 内置目录，支持嵌套目录及命名目标，点击跳至对应页。没有书签的 PDF 显示空状态。此入口不创建用户自定义书签；无文档内目标的外部书签不会自动打开网址。切换文档时导航内容同步切换。

查找页提供文本输入、查找按钮、“区分大小写”和“全字匹配”开关。点击查找或按 Enter 后扫描全部页面，过程中显示环形进度；所有结果逐行列出，悬停可查看完整摘要，点击定位到实际命中文字。命中使用浅黄色高亮，缩放后重绘；搜索标记不写入批注、PDF 文件或备份。清空输入并查找可移除结果，切换 PDF 自动清除旧文档结果。

文字层与画布统一使用 PDF 字体、页面旋转、裁切框和页面单位；按实际 DOM 字宽校正文字段，并补齐精确尺寸与旋转规则。0.1.3 的对齐回归覆盖 25%–400% 缩放、部分单词、旋转/裁切页及高 DPI 嵌入中文字体。

## 划词、句子与段落翻译

在 PDF 中选择文本，**松开鼠标或触控后**才发起翻译；拖动尚未结束时仅更新选区/标记状态，不调用词典或翻译 API。键盘选区也支持在选择快捷键释放后提交。一个英文单词始终走在线词典，不会调用 LLM；Free Dictionary 与 Wiktionary 英文词典并行请求，优先显示可用释义，中文释义和词形也独立加载，避免一个站点超时阻塞所有结果。词性、音标、例句、近义词、词形以实际词条提供的内容为准；仅中文释义可用时明确显示详细词典未连接，不编造缺失内容。原文区域使用较紧凑的字号和行距。

多个词或整段文字默认使用 MyMemory 在线翻译，无需 API Key。右上“翻译设置”在按钮下方打开紧凑浮层，下拉菜单逐行列出预置在线翻译和全部已配置 LLM API；可单独选定翻译 API，不必改全局默认服务。也可调整原文语言、目标语言和 LLM 风格。默认风格为学术论文，也可改为直译、通俗解释或技术文档。

本地清洗处理跨行断词、连续页边行号、引用标记和空白；保留年份、数字和数学上标。LLM 提示额外要求识别脚注、尾注、页眉页脚等排版噪声。复杂双栏、脚注串入正文等情况仍可能需要人工核对。划词结果仅保存在当前页面内存中，不进入备份。

免费在线服务需要互联网、可能限流，并受所在地网络条件影响；它们不是应用内置的离线翻译模型。原文语言默认英文，可在设置中修改。

## 全文翻译与 PDF 输出

打开文档 → 右栏“全文翻译” → 选择目标语言、API 和展示方式 → “开始全文翻译”。

| 模式 | 实际行为 |
| --- | --- |
| API 支持 PDF 输入 | 以完整 PDF 的 Base64 文件内容发送给所选模型；模型须支持该接口的文件输入 |
| 普通文本 API | 浏览器提取全部页面文字后发送，不静默截断；扫描 PDF 需改用支持文件输入的视觉模型 |
| 直接展示 | 流式接收 Markdown，渲染标题、段落、粗斜体、字体颜色、KaTeX 行内/块公式、代码高亮、表格和安全内嵌样式；图片以占位描述表示 |
| 本地排版生成 PDF | 将完整译文按页面排版后生成 PDF，可下载或在左侧打开；此导出为视觉版 PDF，文字、公式、表格被栅格化，不提供可搜索文字层，也不复刻原 PDF 版式 |
| 模型直接生成 PDF | 通过 Responses + Code Interpreter 请求真正的 PDF 文件，读取容器文件引用并下载；只有明确支持文件输出的服务可用，不把普通文本伪装成 PDF |

圆环进度按真实请求阶段显示 PDF 上传中、LLM 分析中、结果转换中。停止或网络中断时保留已收到内容；服务端长度限制会作为未完成结果明确显示。应用不设置 `max_tokens` 强制截断输出。全文与完整历史可能超过所选模型的上下文限制，此时需选择更大上下文模型。

首段全文译文到达时，顶部参数区会动画折叠为一行“结果转换中”状态栏；滚动译文时状态栏保持吸顶。点击右侧箭头可重新展开，后续输出不会强制收起已手动展开的参数。状态栏也提供停止操作，完成后保留译文展示空间。

PDF 文件输入优先采用所选协议的标准格式；若 Chat 兼容网关明确返回 `file must have a file_id or file_data`，会携带相同完整 PDF 按扁平文件字段兼容重试一次。其他 400 错误不盲目重试，也不会悄悄降级成文本。模型是否能处理 PDF 仍取决于服务商能力。

翻译后 PDF 会保存为单独文档，并与原文共享 AI 对话。浏览器支持文件选择器时，可指定保存位置，否则使用浏览器默认下载流程。

点击“在左侧打开译文 PDF”开始转换时，该按钮显示与现有图标一致的旋转进度图标并暂时禁用，转换、入库和打开完成后恢复；失败时也会恢复，允许重试。

## AI 问答

- 问答使用当前 PDF 的完整文字或文件以及所选对话的全部先前消息；不会按固定轮数裁剪。
- 可新建多个独立对话、重命名、切换历史并继续提问。切换 PDF 会切换关联历史；原文与翻译后 PDF 共享同一组历史。
- 用户消息先写入 IndexedDB，再发出网络请求；流式每个增量先提交存储，再显示。停止、请求失败或刷新后保留已经成功落盘的内容。
- `Enter` 发送，`Shift + Enter` 换行。流式生成期间可停止，也可以切换到其他文档继续阅读。
- 提交问题后、首段回答到达前，助手消息里显示“正在思考”环形动画；开始输出后由回答替换，停止或失败后移除。恢复旧的未完成记录时不会假装后台仍在思考。
- 已关闭应用后尚未从网络接收的数据无法保存；浏览器强制终止、磁盘故障或主动清理站点数据也无法由网页绝对保证恢复。请使用备份和云同步。

## 多 API 与海姆休息室迁移

“设置 → 模型与 API”支持任意多组 `API Key`、`Base URL`、`model`，保留原项目的 `chatProviders`、`defaultChatProviderId` 字段语义，并增加名称、协议和 PDF 能力标记。

- 支持 Chat Completions 兼容服务与 Responses API；本地兼容模型可以留空 Key。
- 可获取服务商模型列表、测试真实响应、设置默认服务。
- 首次向导有 DeepSeek、OpenAI、MiMo、自定义入口；型号以服务商实际提供的模型 ID 为准。
- 点击“迁移海姆休息室配置”，选择原项目导出的 ZIP 或设置 JSON，会合并模型配置；不导入角色扮演专用数据库。
- 本项目对 `D:/Models/vibe_coding/fritia_online_next_chat` **只读参考**，没有修改、删除、新增或写入原项目文件。迁移实现及许可证说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。

浏览器直接请求服务商，因此对方必须允许当前站点的 CORS。Key 存在本机 IndexedDB，不能作为公开站点共享的服务端密钥。

## 备份与云同步

“设置 → 备份与存档”可以导出 ZIP，包含所有 PDF、编辑记录、全文译文、对话和界面设置；API Key 与云凭据默认不包含，可显式勾选。输入备份密码则生成 AES-GCM 加密的 `.pbak`，密码不写入存档。

导入前检查版本、记录引用和每个 PDF 的 SHA-256；校验通过后用单个 IndexedDB 事务合并。导入不清空现有库。冲突消息、译文或批注保留恢复副本；对话界面会标注恢复副本。可选择恢复设置并合并 API，缺省空密钥不会覆盖本机已有密钥。请妥善保管加密备份密码。

“设置 → 云同步”配置 WebDAV 地址、目录、账号和应用密码后，可测试连接或立即同步，也可启用应用打开期间每 30 分钟自动同步。流程为读取云端 → 校验 → 合并本地 → 条件上传；不删除云文件。云端不携带 API Key 和 WebDAV 凭据，设备连接设置不会被自动恢复。

WebDAV 必须支持 HTTPS（HTTPS 网页不能访问普通 HTTP 服务）、CORS、`GET / PUT / MKCOL / PROPFIND`、条件请求 `If-Match / If-None-Match`，且通过 `Access-Control-Expose-Headers: ETag` 暴露强 ETag。远端更新导致 `412` 时停止覆盖，保留本地合并结果，重新同步即可。

“永久保存”是浏览器允许范围内的持久化：应用会请求 Storage Persistence，但配额、隐私模式、用户清除站点数据等仍由浏览器控制。浏览器的不同域名、端口、配置文件彼此隔离。

## 桌面与移动端

桌面使用侧栏、PDF 栏、翻译栏三部分，分栏宽度可拖动或键盘调整。移动端使用底部导航，在阅读、翻译/AI、文档管理之间分屏切换；不会将两个主栏叠在一起。手机选词后留在阅读页，便于继续点选批注工具；译文仍自动请求，可点击底栏查看。单行文件卡片保留约 44px 的触控高度。两套交互和样式分别位于 `src/js/ui/desktop.js`、`src/js/ui/mobile.js`、`src/styles/desktop.css` 和 `src/styles/mobile.css`。

构建产物不依赖操作系统，可在 Windows/Linux/macOS/Android/iOS 的现代浏览器运行，并可作为 Tauri 的 `frontendDist`。**当前交付是静态 Web 应用，尚未制作或验证 Tauri 安装包。**

## 开发验证

```sh
npm run check
npm test
npm run test:e2e
npm run build
npm run test:dist
```

端到端测试优先使用 Windows 已安装的 Chrome；其他平台先执行 `npx playwright install chromium`，或设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。测试使用临时浏览器配置和合成 PDF，不读取用户真实文档、Key 或浏览器资料。外部 LLM、词典和云服务测试通过可控响应模拟，真实服务可用性需结合网络与账号验证。`test:dist` 检查构建后子路径静态部署、禁止外部网络时的 PDF 渲染、中文批注导出及恢复。0.1.3 已通过 17 项单元测试、28 项浏览器用例和生产静态检查。

`npm run format` 只格式化应用、样式、工具与测试，不修改用户提供的 UI 规则或参考项目。生产构建约 16.3 MiB，包含离线可加载的 PDF 资源和中文导出字体；只有实际导出时加载 PDF 编辑模块与中文字体。

详细模块、数据模型、DOM 映射、函数与验证记录见 [STRUCTURE.md](STRUCTURE.md)、[DEVELOP.md](DEVELOP.md)、[CHANGELOG.md](CHANGELOG.md)。
